# Rent Finder — Front-end (Next.js)

A documentação completa do produto, da arquitetura e dos comandos do **monorepo** está no [**README na raiz do repositório**](../README.md).

## Arranque rápido

```bash
npm install
cp .env.example .env.local   # definir DATABASE_URL (Supabase / Postgres)
npm run dev                  # http://localhost:5000
npm run build
```

Variáveis e deploy (Vercel, variáveis de ambiente): ver secções correspondentes no README principal.
